# Biglight Component Library

Welcome to the Biglight Component Library documentation. This library provides a comprehensive set of reusable UI components built with Preact, Tailwind CSS, and design tokens.

## Overview

This component library is designed to support multiple brands through a flexible design token system. All components are built with accessibility, responsiveness, and theme switching in mind.

## Theme Switching

Use the **Theme** toolbar control in Storybook to switch between:
- **Brand A**: Orange/teal color scheme 
- **Brand B**: Different visual styling 

Components automatically adapt their colors, fonts, and spacing based on the selected theme.


## Design Tokens

Design tokens are stored in `src/tokens/source/figma-tokens.json` and are automatically converted to:

- **CSS Custom Properties** - For runtime theme switching
- **Tailwind Configuration** - For utility class generation
- **TypeScript Types** - For type-safe token access

See the individual component documentation for detailed usage examples and API references.


## How CSS is Generated from Figma Tokens

Design tokens are defined in `src/tokens/source/figma-tokens.json`. These tokens include color, spacing, border radius, and typography values specific to each brand.

The process to generate CSS from these tokens is as follows:

1. **Parsing Tokens:**  
   The file [`src/tokens/parser.ts`](./tokens/parser.ts) parses and resolves token references in the JSON, ensuring that all values are direct.

2. **Structured Theme Objects:**  
   Parsed tokens are mapped into structured TypeScript objects for each brand via [`src/tokens/themes.ts`](./tokens/themes.ts), making tokens easy to access in components.

3. **Generating CSS Custom Properties:**  
   The function [`generateThemeCSS`](./tokens/generate-css.ts) takes a theme (e.g., `brandA`), and generates a string of CSS custom properties. Each token value is converted into a CSS variable like `--color-primary`, `--spacing-md`, etc.

   For example:
   ```css
   :root[data-theme="brandA"] {
     --color-primary: #fc4c02;
     --color-background: #ffffff;
     --spacing-md: 16px;
     /* ...and all other token values */
   }
   :root[data-theme="brandB"] {
     --color-primary: #246bfd;
     --color-background: #f9fafd;
     /* ... */
   }
   ```

4. **Applying the Theme:**  
   At runtime (and in Storybook), the appropriate theme's CSS variables are attached to the `:root` element or a wrapping container by toggling the `data-theme` attribute. Components reference these CSS variables for their styling, allowing for seamless theme switching without reloading stylesheets.
